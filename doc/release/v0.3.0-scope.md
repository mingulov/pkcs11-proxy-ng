# v0.3 Stabilization Release

v0.3.0 is a stabilization release of the audited v0.2 line: it ships the
hardened tree with no new features and no scope expansion. Its content is
the engineering-audit remediation campaign (gap analysis, P0–P2 defect
remediation, operator and assurance documentation, release hardening)
plus dependency and CI maintenance, as a stable baseline for the
provider-matrix qualification that follows.

- One logical client in one trusted security domain per daemon and
  provider instance (unchanged). `max_contexts = 1` limits admission;
  it does not clear native authentication state or isolate private
  objects.
- Multi-client support is NOT in this release. The multi-client plan
  previously targeted here moves to [v0.4.0](v0.4.0-scope.md) with no
  delivery-date or support commitment.
- Provider-matrix qualification is NOT in this release. The full
  non-mock provider comparison lands in v0.3.1; see the [v0.3.0 release
  notes](v0.3.0-release-notes.md) for the evidence this release does
  carry.

[Public support](beta-support-matrix.md) expands only after
implementation, evidence, and independent review establish the new contract.
