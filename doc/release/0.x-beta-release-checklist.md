# `0.x` Beta Release Checklist

Use this checklist before tagging a public beta. Leave a box open until the
result is verified for the exact release source and its evidence is retained.
The latest public release is `v0.1.0`; `v0.2.0` is an unreleased testing
candidate. See the [release notes](v0.2.0-release-notes.md) for its scope and
remaining gaps.

## Build and quality

Verify the repository from a fresh clone, without the private planning
workspace or an OASIS source tree:

- [ ] `cargo fmt --all --check` is clean
- [ ] `cargo check --workspace --all-targets --locked` is clean
- [ ] `cargo test --workspace --locked` passes (source-grounded OASIS tests skip when
      `PKCS11_PROXY_NG_OASIS_ROOT` is unset)
- [ ] `scripts/release-dry-run.sh` produces the expected artifacts
- [ ] The exact source commit, test suite, test data, and results are recorded

## Provider comparisons

Follow [parity validation](parity-validation.md):

- [ ] Run the full suite directly and through the proxy for SoftHSM2, NSS
      softokn, and Kryoptic, retaining dated reports and their provenance
- [ ] Complete and retain the explicit 30-provider non-mock comparison matrix
- [ ] Compare outcome classes, investigate each difference, and record the
      disposition. Fix proxy defects; report provider behavior seen directly
      upstream. Do not normalize provider results in the proxy.
- [ ] Resolve every release-blocking proxy defect and record accepted limits in
      the [support matrix](beta-support-matrix.md)

## Public documentation

- [ ] README scope agrees with the [support matrix](beta-support-matrix.md)
- [ ] [mTLS setup](mtls-setup.md) matches the config and private-key permissions
- [ ] [Operator runbook](../runbooks/operating-pkcs11-proxy-ng.md) and
      [error reference](../error-reference.md) are current
- [ ] Documentation distinguishes released behavior from unreleased changes
- [ ] Plain TCP without mTLS has no public support claim unless explicitly
      decided; no production-ready or broad-vendor claim appears without evidence
- [ ] Licenses and crate metadata (`version`, `license`, and preferably
      `repository` and `description`) are ready

## Release

- [ ] Version is updated in `Cargo.toml` `[workspace.package]`
- [ ] Release notes state the scope, validated providers, and limitations
- [ ] The tag points to a clean, verified tree
- [ ] Separate approval has been received to tag, push, and publish
