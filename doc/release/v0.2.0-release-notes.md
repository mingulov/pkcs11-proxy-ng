# v0.2.0 Release Notes

**Status: local candidate; unreleased.** Public latest is `v0.1.0`; the local
target is `v0.2.0`.

## Local changes

The `[Unreleased]` changelog records local gateway work: opt-in gateway
authorization and rate/quota controls; resilience detection and attribute
coalescing; tamper-evident audit with data-plane gap reporting; startup backend
attestation; packaging mirrors for Alpine APK, Amazon Linux RPM, and CI; and
workspace MSRV `1.88`. Cargo workspace metadata is authoritative; APK/RPM/CI
literals are checked mirrors. This work is implemented locally, partially
covered, and unreleased; local unit and integration coverage is not a
transparency matrix.

## Current limitations

- Denial is not constant-latency.
- Attestation runs at startup only; it has no config hash and no reconnect or
  hot-swap re-attestation.
- Audit contains operational metadata, never PINs, key material, or raw request
  payloads.
- Data-plane audit can drop records and reports gaps.
- Fail-closed audit can occur after a backend side effect.
- `EventClass::Deny` remains reserved rather than emitted.

## Release blockers

- Record the intended check commit and clean framework/test-data provenance.
- Produce dated direct, proxied, and comparison evidence for SoftHSM2, NSS
  softokn, and Kryoptic.
- Produce an explicit 30-provider non-mock matrix.
- Pass the standalone-clone gate.
- Obtain separate approval to tag, push, and publish.

## Explicit exclusions

This candidate has no Observatory, recorder or payload capture, target replay,
cassette playback, live mirror, or public `v0.2.0` artifact.
