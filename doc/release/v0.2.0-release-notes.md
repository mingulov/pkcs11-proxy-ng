# v0.2.0 Release Notes

**Status: local candidate; unreleased.** Public latest is `v0.1.0`; the local
target is `v0.2.0`.

## Local changes

The `[Unreleased]` changelog records local gateway work: opt-in gateway
authorization and rate/quota controls; resilience detection and attribute
coalescing; tamper-evident audit with data-plane gap reporting; startup backend
attestation; transparent-forwarding fixes for NULL/data forwarding and bounds,
mechanism-payload safety, Verify/Digest init forwarding, and close-attempt
session-cache eviction;
packaging mirrors for Alpine APK, Amazon Linux RPM, and CI; and workspace MSRV
`1.88`. Cargo workspace metadata is authoritative; APK/RPM/CI literals are
checked mirrors. This work is implemented locally, partially covered, and
unreleased; local unit and integration coverage is not a transparency matrix.

## Current limitations

- Denial is not constant-latency.
- Diagnostic bundles are private, allowlisted metadata snapshots. They exclude
  raw logs, configuration files, environment values, and command errors, and
  use descriptor-relative, create-only Python standard-library archive output
  rather than external archive tools. They must still be reviewed before
  sharing. Arbitrary-log sanitization is not a supported promise.
- Attestation runs at startup only; it has no config hash and no reconnect or
  hot-swap re-attestation.
- Audit contains operational metadata, never PINs, key material, or raw request
  payloads.
- Data-plane audit can drop records and reports gaps.
- Fail-closed audit can occur after a backend side effect.
- `EventClass::Deny` remains reserved rather than emitted.

cassette playback, live mirror, or public `v0.2.0` artifact.
